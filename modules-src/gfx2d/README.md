# gfx2d

2D sprites with the full Scratch-style block set.

## Lua surface (selected)
`Sprite.new(name, costume)`, `:goto/:glide_to/:move_steps/:turn/:point_in_direction`,
`:change_x/:change_y`, `:say/:think` (with the `speech` module), `:show/:hide`,
`:set_size/:change_size`, `:set_layer/:go_front/:go_back`, `:touching(...)`,
`:distance_to(...)`, `:clone()`, `:destroy()`, properties `x/y/direction/size/visible`.
